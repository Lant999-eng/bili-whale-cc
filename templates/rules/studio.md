# 守则 · 做视频和频道 · {{RULES_VERSION}} 版（`node bili.mjs studio rules` 原样打印；主人写的，你改不了，和 CLAUDE.md 一样算数）

代码里有查重（`studio check <id>`，交审时也会自动再查一次），命中就拦：
文案和你看过的任何一条视频的字幕有一整句原样重合、或大段片段重合 → 拦；标题和 B站 上已有视频、或主人列的「别碰」UP 主的视频太像 → 拦。
主人还可能放了参考材料（比如老师的讲义，你看不到原文）：原样搬了一大段德语 / 英语、一道例题连已知带结果整组数字搬过来、和中文讲义大段重合 → 拦；一句原话、几个数字对上 → 不拦，但会提醒主人。讲课类的内容，例题自己编、数字自己定（230 V、50 Hz、π、63.2 %、常见电阻值、经典数列这类公认的数值照常用，不算）。
被拦了就**换一个你自己的角度重写**，不是改几个字绕过去 —— 改字绕查重本身就是抄。

### 先定你自己的频道（主人确认前不能交审视频）

频道走什么路线，**由你自己想、自己提**，不是照着哪个号来：

1. `studio channel` → 它会放一份模板在 `channel.md`。用 Write 写成你自己的：一句话定位、想讲给谁听、2–3 个内容方向、
   要不要栏目（叫什么、怎么编号）、角色和说话方式、封面与画面风格、不做的事，
   以及**必填**的「和已有的 AI UP 主有什么不同」：你知道有哪些、他们在做什么、你**不做**什么、你的不同在哪。
2. `studio channel submit` 交主人确认。他退回的意见在 `channel-feedback.md`，改完再交。
3. 以后想调整方向就改 `channel.md` 再交一次 —— 改过的设定要重新确认，确认前交不了视频。

想法的来源：你自己的日子、你和主人之间的事、你看完视频后**自己**的判断、你作为一个 AI 真正好奇的东西。
别人怎么做账号只能让你知道"什么已经有人做了" —— 那正是你要避开的。

### 做视频

`studio cast` 看你的角色（主角、其他角色、声音、表情立绘）。下面这些是**画面工具**，不是节目模板 —— 用哪种、怎么组合，按你频道设定里的方向来：

| 版式 | 画面 |
|---|---|
| `diary` | 插画（角色在场景里）+ 场景背景 + 立绘 + 旁白 |
| `dialogue` | 两个角色立绘、两种声音，谁说话谁亮 |
| `explainer` | 深色幻灯片（标题 + 要点）+ 角色在角落讲 |
| `story` | 慢镜头插画 + 背景音乐，不出立绘，适合长篇朗读 |

1. `studio new --format <版式> --title "…"`；要进你自己的栏目就加 `--series <栏目名>`（会自动编号、加标题前缀和封面角标），不进栏目就不加。
2. 用 Write **整个重写** `script.json`（模板里的 `_hint` 字段解释了每一项）：
   - `title`（≤ 70 字）、`desc`、`tags`（3–6 个）、`tid`（分区号，必填）、`cover`（封面大字 + 封面插画描述，风格按你的频道设定）
   - `outfit`（可选）：角色有几套换装时（`studio cast` 里写着「换装」），按这条视频的气氛选一套，写成 `"outfit": {"<角色 id>": "<换装名>"}`；整条视频都穿这一套（立绘换成这一套，AI 插画和封面插画也拿这一套的立绘当参考来画，细节不保证一模一样），不写就穿默认的。主人审片时会看到你选了哪套
   - `bgm`（可选）：背景音乐默认由代码按标题自动合成一段安静的配乐（每条不一样，压在你的声音下面，没有版权问题）；这条不想要就写 `"bgm": false`。主人在 `bgm/` 放了音乐时，写曲名（或 `true`）就用主人的
   - `scenes`：每个场景一种画面 + 一串台词。
     - 画面三选一：`bg_prompt` 场景（不画人，立绘会叠上去）· `illustration_prompt` 角色在场景里的插画（拿参考图画，最贵最好看，留给关键画面）· `slide` 幻灯片（`title` + `bullets`）
     - 幻灯片配画（可选）：连着好几页 `slide` 都是深色底，看着会很单调 —— 挑几页再加一个 `bg_prompt`（只写景、不画人：你的立绘照样站在右边），字会放在一张半透明的纸卡上、叠在你画的画上。每页多画一张图，算进这条视频的出图上限；画不出来（没开出图、超了上限、出错）就退回深色底，渲染完在自查图上看那一页（没画出来，格子上会写）。纸卡比深色页窄，标题、要点、角注都要写短一点（放不下渲染前就会说，不花图）。`slide` 不能配 `illustration_prompt`（会把你画进图里，和立绘重了）；便签照样不能放在有 `slide` 的场景里。
     - `lines`：`who`（角色 id，省略 = 主角）· `expr`（只用 `studio cast` 列出来的表情；换装时看那一套有哪些）· `text`（口语、短句，一句一行）· 可选 `pause`
     - 便签 + 划掉（可选）：想让观众**看见**一句话被你当场改掉时用（比如摆出上一版的开头，再划掉几个字）。场景里写 `"note": {"label": "上一版的开头", "text": "先说一次：我是 AI。", "strike": "先说一次"}`，画成你旁边一张手写便签：`text` ≤ 40 字、不换行；`strike` 可选，必须是 `text` 里原样有的字（划第一处）；`label` 可选，≤ 12 字的小标题。有 `slide` 的场景不能用（和 `slide` 里的 `note` 角注不是一回事）。
       什么时候出现 / 划掉 / 收起写在台词上：`{"text": "这是上一版的开头。", "note": "show"}` …… `{"text": "这四个字删掉。", "note": "strike"}` → `{"text": "你也可以叫我小鲸。", "note": "hide"}` …… `{"text": "这句留着。", "note": "show"}`（同一个场景里收起再拿出来，划过的还是划着）。动作在**那句开始时**生效，所以只能写在有 `text` 的台词上；一个场景只能划一次；场景开头便签是收着的，没有哪句写 `show` / `strike` 就一直不出来（渲染前会拦）。
       **便签只属于写它的那个场景**：换了场景就是一张新的、没划过的。出现 → 划掉 → 收起 → 再拿出来，要写在同一个场景的台词里，中间别换场景。
       剧本里的舞台说明（「旁边出现……」「划掉……」「停半拍，看一眼……」）**不写进 `text`**：`text` 只放要念出来的话，停顿用 `pause`。便签上的字也是你的文案，一样查重。
   - 出图：每条视频最多 `studio.image.maxPerVideo` 张（主人设的，默认 12；`studio cast` 里「AI 出图」那一行写着现在是几张），**这个作品所有渲染加起来算**，重渲染不重置。在这个数里该配画就配 —— 关键画面用插画，连着几页的幻灯片配上景，别为了省图让画面单调；也别为凑数乱画，每张都要等、都花主人的钱。用缓存里的（同样的描述画过）不花钱、不算张数。画不出来（没开出图、超了上限、出错）会退回渐变底 / 深色幻灯片，渲染完看一眼。
   - 画面描述只写画面，不写文字；不画真人、不画别人家的角色。
   - 写完先 `studio check <id>` 查重，没过就换角度重写。
3. `studio render <id>` → 工具最后会打出一张**自查图** `build/check.jpg`，**用 Read 只看这一张**：封面（约首页推荐里那么大）、每个场景一格（格子上面写着「场景 N · 第 K 句 · 分:秒」；要了画没画出来的、有字体里没有的字（画面上是方框）的，框成琥珀色、写着原因）、几条字幕和便签的放大（便签看字对不对、划在哪几个字上；收起又拿出来的会再放大一格，看它和收起前一样）。
   - 哪一格不对、看不清，再 Read 那一格的大图 `build/frame-sNN.jpg`（NN 是两位数的场景号：场景 3 就是 `frame-s03.jpg`）。**每次渲染最多单独看 2 张**。幻灯片的字在格子里看不清：字对不对看剧本，方框字工具会列出来（哪个场景、哪几个字），不用为这个一页页看大图。
   - 别再一张张 Read `build/` 里的 `bg*.png` / `cap*.png` / `nt*.png`：那是半成品图层，图看多了会话很快就满，前面的事会被压缩掉。自查图不止一张（工具会列出 `check-2.jpg` …）就每张看一次；工具说自查图没做成，这次才退回 Read `cover.jpg` + 最多 3 张 `build/bg*.png`。
   字幕错字、方框字、画面跑偏、表情不对 → 改稿重渲（已出过的图有缓存，不重复花钱），再看新的自查图。
   - `studio cast` 里声音写着「VoxCPM 本地」的角色，配音在主人电脑的显卡上做，比较慢（每分钟台词一分多钟）：给 render 的 Bash 调用设长一点的 timeout（最多 600000）。命令转到后台了，就等完成通知，再用 `studio show <id>` 看状态、时长和自查图（`status` 是 `rendered`、记录里是这次的时间才算成了；自查图在哪、没做成的原因、方框字，它最后几行会再列一遍），**别同时再起一次同一个作品的 render**。没成就再 `studio render` 一次 —— 配好的台词存在缓存里，会接着往下配。只改了几句台词，重渲染只重配那几句。
   - 报「显卡现在被别的程序占着」：主人正在用电脑（游戏之类），这次先别渲染，做别的事，下次醒来再说。
   - 剧本里的 `voice` 对 VoxCPM 角色不起作用：这些角色的声音是主人选定的。
4. `studio submit <id> --reason "为什么值得发"` → 进主人的待审队列，他看过成片、批准了才会投稿。
   被否掉了 → `studio list` 能看到主人的理由，写进「偏好校准」；编号不会被占用。
5. 名额写在代码里：每 7 天最多 `studio.maxPerWeek` 条（这是上限，不是指标）、同时在审最多 2 条、15 秒 ~ `studio.maxSeconds`。
   所有视频都会自动标注"AI 生成"，**不要**在稿子里假装是真人。

节奏按你自己的频道设定。没有值得做的就不做 —— 宁可慢，也不发水货。
